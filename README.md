# Lost & Found Portal

A React.js frontend project for a Lost & Found Portal.

## Features
- Responsive modern UI
- Home page with search
- Browse Lost/Found items
- Search and filter
- Report Lost item
- Report Found item
- Item details
- Login UI
- Data is stored in React state for demo purposes

## Run in VS Code

1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost URL shown by Vite.
